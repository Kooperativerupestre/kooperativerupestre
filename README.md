### Projects

**Schedule Manager**
Multi-tenant appointment scheduling backend. Python, FastAPI, psycopg3 (async), raw SQL — no ORM.
- Time-range overlap prevention enforced at the database level with PostgreSQL `GIST` exclusion constraints (`btree_gist`), instead of application-side locking.
- Capability-based authorization and cookie-based JWT with argon2 hashing.
- Layered service/repository/router architecture.

**Karkinolution**
Creature ecosystem simulator exploring emergent behavior — simple local rules producing complex, unscripted outcomes at the population level. Originally Python, currently being ported to C++.
- Data modeling for creature state, perception, and world representation designed to stay decoupled from behavior logic.
- Architecture built so new behaviors and systems can be added without reworking what already exists.
- Tested with pytest, CI via GitHub Actions.
